## [0.1.0] - 2026-08-09

This is the first release of the Rust implementation of Agentlog.

### Added

- A local, read-only terminal application that brings session histories from
  Codex, Claude Code, OpenCode, Gemini CLI, Cursor, and Kimi Code into one
  searchable timeline without modifying the original files.
- Installation on ARM64 and x86-64 macOS and Linux through GitHub Releases, the
  `choplin/tap` Homebrew tap, or a Nix flake.
